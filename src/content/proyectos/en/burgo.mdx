## What it is

Burgo is a family of everyday apps built for Maracaibo that also work outside Venezuela, in Spanish and English. Each one does one thing: **Cancha** organizes pickup games with a waitlist, balanced teams, chat and payments; **Pique** is live group trivia; **Brío** tracks workouts and calories with local food; **Cuadre** handles personal finances in dollars and bolívares; **Fase** shows, sector by sector, whether the power is out. **Account** is the single sign-on and **Admin** the central panel. [Sobre](/en/proyectos/sobre/), the price radar, started here and is now a separate service.

## How it is built

The backend is a modular monolith in Go: every module owns its schema in PostgreSQL (with PostGIS for geographic data) and talks to the others through internal events, so it can be split into services if it ever needs to. Redis shares real-time state (chat, alerts) across instances. The apps are React and Vite PWAs in a monorepo with shared UI, auth, API client and i18n packages.

Every app has its own theme (colors, heading typeface and component shapes) on a shared body typeface, and a guard test watches the AA contrast of every app’s states.

One account works everywhere (email, Google or Apple), with verification, password recovery, push notifications and an audit trail of admin actions.

## How I run it

Everything runs on my own VPS with Docker and Caddy (automatic HTTPS), with separate development and production environments, daily backups and self-hosted transactional email. Continuous integration runs Go tests, front-end checks and end-to-end Playwright tests before every deploy. Every app has its PDF manual.

## What it taught me

Designing a whole system, not just a screen: modeling data across several domains, deciding where each boundary goes, keeping accounts secure and running in production something I use every day.
